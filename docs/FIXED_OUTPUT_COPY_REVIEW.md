# 聆序固定输出文案审阅稿

> 快照日期：2026-08-24<br>
> 用途：在此文件直接修改每个代码块中的文案，再交由工程实现。<br>
> 注意：本文件是审阅稿，不会自行改变 Bot 的运行文案；变量占位符 `<…>`、Discord
> 指令名和文件名应保留，除非明确要改变对应功能。

## 适用范围与约定

- 覆盖正式会议、议程 Markdown 导入、Slash/按钮/私信交互、会后发布与常驻语音助手的
  直接用户可见固定文案。
- `<会议ID>`、`<状态>`、`<议程标题>`、`<投票标题>`、`<人数>`、`<时长>`、`<频道>`、
  `<用户>` 等均由系统填充，不能改成具体会议内容。
- 正式会议的语音播报失败时，会将同一段文字发送到授权文字频道；因此“语音文案”同时也是
  该降级文字输出的文案。
- 会议纪要 `minutes.md`、常驻语音助手的正常回答与状态/议程清单都含
  运行时内容，不是固定文案；它们在本文只保留外层模板。
- 每个编号下的代码块均可直接编辑；编号是后续实施时的确认依据。

## A. 正式会议语音播报



### VOICE-03 进入中文议程（含时长）

```text
现在进入议程: <议程标题>。该流程预计持续<分钟>分钟。
```

### VOICE-04 进入中文议程（无固定时长）

```text
现在进入议程: <议程标题>。该流程无固定时长, 请主持人在流程完成后手动进入下一流程。
```


无固定时长：


## G. 当前没有独立频道公告的环节

以下状态会推进系统，但当前不会额外向文字频道发固定通知：等待参会者同意、同意尚未齐全、
会后 Job 已排队/正在处理、会后 Job 失败、Worker 已完成但尚未发布。其可见反馈仅来自相邻的
Slash 回复、语音播报、最终发布或错误回复。

## H. 实施边界

- 修改本审阅稿不会改变运行时；确认后应将对应编号的内容同步到 Python 源码并运行相关测试。
- 改动隐私承诺、同意/撤回提示、投票含义、发布说明或 DeepSeek 表述前，应先确认是否改变产品
  行为或合规含义。
- 不要将真实会议标题、姓名、逐字稿、纪要、音频路径、凭据或 Discord 身份写入本文件。
